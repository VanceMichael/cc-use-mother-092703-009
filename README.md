# 葡萄酒展会产区与订单履约

管理葡萄酒节的产区展位、产品批次、试饮库存和订单履约。

## 参与方与事实

主要参与方包括展会主办方、酒庄与产区代表、经销商、检测人员、物流人员。领域资料记录以下已经确认的事实：

- 2026新疆丝绸之路葡萄酒节设置1.25万平方米展区
- 四大核心产区和阿克苏特色产区集中亮相
- 展会覆盖葡萄酒、文创包装和农特产品全链条品类

## 业务约束

- 产品批次
- 检测证书
- 试饮库存
- 经销商资质
- 温控标签
- 订单履约

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/wine_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
